# React design rules
- Functional typed React components with predictable state boundaries and accessible controls.
- Clean, warm off-white reading surface, graphite text, muted indigo action, pale amber highlight; no noisy gradients/gamification.
- UI must show loading, empty, offline, error, and recoverable states; no placeholder buttons.
- Check 1366x768 minimum and 2560x1440. Sidebar must collapse/resize without covering text permanently.
- Tests use queries by accessible role/text over brittle CSS selectors; never invent screenshots.
